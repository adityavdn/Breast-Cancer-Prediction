# 🎗️ Breast Cancer Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Healthcare](https://img.shields.io/badge/Healthcare-Oncology-pink.svg)

## 📖 Overview

Binary classification model to predict breast cancer diagnosis (Malignant/Benign) using cell nucleus measurements from fine needle aspirate (FNA) images. Supports early cancer detection.

## 🎯 Features

- Malignant vs Benign classification
- Feature importance analysis
- Multiple algorithm comparison
- Medical decision support

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Usage

```bash
git clone https://github.com/adityavdn/Breast-Cancer-Prediction-.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Key Features (FNA)

- Radius, Texture, Perimeter
- Area, Smoothness
- Compactness, Concavity
- Symmetry, Fractal Dimension
